# Madar

Madar is an interactive astronomy website designed to make space exploration simple, visual, and engaging. It introduces visitors to planets, stars, galaxies, missions, discoveries, and the solar system through a responsive collection of educational pages.

## Website Sections

| Section | Description |
| --- | --- |
| [Home](index.html) | A visual introduction to the universe and the website. |
| [Planets](2-Planets.html) | Explore the planets of our solar system. |
| [Planet Details](3-Planets_Details.html) | View additional information about individual planets. |
| [Stars & Galaxies](4-Stars_Galaxies.html) | Discover stars, galaxies, and other deep-space objects. |
| [Missions](5-Missions.html) | Learn about important space missions and exploration. |
| [Discoveries](6-Discoveries.html) | Browse notable discoveries in astronomy and space science. |
| [Solar System](7-Solar_System.html) | Navigate an overview of our solar system. |
| [About Us](8-About_Us.html) | Meet the team behind Madar. |
| [Contact](9-Contact.html) | Send a message through the contact form. |
| [Favorites](11-Favorites.html) | Save and review selected space content. |

## Technologies

- HTML5
- CSS3 and SCSS
- JavaScript
- Bootstrap
- Font Awesome and Animate.css
- Responsive design for desktop and mobile screens

## Run Locally

Because Madar is a static website, no build step is required. Open [index.html](index.html) in a browser, or serve the project folder with any local static web server.
